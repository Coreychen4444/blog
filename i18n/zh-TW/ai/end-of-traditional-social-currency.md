從 Muse 爆紅談起，聊聊 AI Agent 時代的身分、信譽與社群網路。

最近 Muse 紅了。身邊不少人開始認真用它，跟它聊天，讓它記住自己的事，遇到選擇的時候先問問它。

看著這股熱潮，我腦子裡一直繞著一個問題：人為什麼這麼想要一個「懂自己」的 AI？

順著這個問題往下想，我碰到了另一個更老的問題。我們到底靠什麼，讓別人知道自己是誰？

## 一、Personal Agent 最後會長成什麼樣子

今天大家說的 AI 助理，多數還停留在「幫你做事」：訂餐、回信、排行程。我覺得這只是起點。

一個 AI 如果陪你夠久，它知道的會遠遠超過你的待辦清單。你讀過什麼書，做過哪些專案，在什麼事情上反覆糾結，哪些判斷後來被證明是對的，你信任誰，誰又信任你。

這些東西累積個幾年，它對你的了解，可能比大多數朋友都深。

到那一步，它就不太像一個工具了。它更像你在數位世界裡的分身，帶著你的經驗、偏好和判斷方式。你不在場的時候，它可以替你回答問題，替你跟別人的 Agent 談合作、交換資訊、做第一輪篩選。

所以我的判斷是：Personal Agent 的終極形態，是數位分身。

後面所有的推演，都站在這個前提上。

## 二、豪車、名錶、名校，其實是同一種東西

先回到社交本身。

兩個陌生人第一次見面，資訊是嚴重不對稱的。我不知道你可不可靠，有多少本事，做成過什麼事。想弄清楚這些，得花很長時間相處、合作，有時候還得踩個雷。

於是人類發明了很多「捷徑」。

手腕上一支百達翡麗，暗示你有錢。開一台保時捷，暗示你混得不錯。名片上印著某大廠總監，暗示你有能力。履歷上寫著 MIT、史丹佛，暗示你聰明又努力。

這些東西做的是同一件事：在對方沒時間了解你的時候，先給出一個大概的答案。我把它們叫做「代理身分」（Proxy Identity）。它們代表你，但它們不是你。

它們為什麼能發揮作用？我覺得可以從「貨幣」這個詞去理解。

一張紙鈔本身不值什麼錢。它能換到東西，是因為所有人都相信它能換到東西。貨幣的價值，來自共識。

貨幣被發明出來，本來就是為了效率。沒有貨幣的年代，人們只能以物易物，要找到一個剛好需要你的東西、手上又剛好有你想要的東西的人，難得要命。社交貨幣解決的也是效率問題：真正了解一個人太慢了，那就先用一個標籤頂上。

社交貨幣也是這個道理。一支錶能代表「成功」，靠的不是它走得比手機準，而是大家預設戴得起它的人大機率有實力。一所學校能代表「優秀」，是因為社會普遍認可它的錄取門檻和培育品質。

有了共識，這些東西就能在陌生人之間「流通」。你不用解釋自己，對方看一眼就懂，就像付錢的時候不用證明鈔票是真的。

不過，光有共識還不夠。為什麼偏偏是名錶、豪車、名校，而不是別的東西？

經濟學裡有個理論叫「訊號理論」。經濟學家麥可・史賓賽（Michael Spence）用它解釋過一個問題：雇主看不出求職者的真實能力，為什麼會看重學歷？他的答案是，學歷不一定直接證明你會做事，但拿下一個好學歷很難，能力差的人很難拿到。正因為取得它的成本高，它才成了可信的訊號。史賓賽後來憑這項研究拿下了諾貝爾經濟學獎。

名錶和豪車也是同一個邏輯。一百多年前，范伯倫（Veblen）就寫過「炫耀性消費」：有錢人買昂貴的東西，很多時候不是因為好用，而是因為別人買不起。貴，本身就是它的功能。

所以一個訊號能不能被相信，關鍵在於造假的代價夠不夠高。誰都能輕易拿到的東西，證明不了什麼。

這也意味著，社交貨幣和真正的貨幣一樣，會貶值。一旦出現一種更難偽造、取得成本卻低得多的訊號，大家就不必再靠一支錶來證明自己，舊訊號背後的共識也會慢慢鬆動。

豪車名錶還有一個特點：大多是消費型負債。買下那天就開始貶值，保養還得持續花錢。很多人明知道不划算還是要買，因為在社交場合它確實「有用」，能換來別人對你的第一印象。

名校稍微不一樣，它背後有真實的篩選和訓練。可它在社交裡被使用的方式，跟名錶很像。別人看到的是一個標籤，看不到你在那四年裡到底學到了什麼，更看不到你之後十年做成了什麼。

Muse 背後的負責人、Meta 首席 AI 官 Alexandr Wang，當年在 MIT 只讀了一年就退學了。今天幾乎沒有人會因為他沒拿到學位而懷疑他的能力，大家看的是他做成了什麼。這個例子在提醒我們：學歷標籤和一個人的真實能力之間，本來就隔著一層。

所以這篇文章想討論的，其實不只是奢侈品。我真正想說的是：

當 AI 能更直接地讀懂一個人的能力、經歷和信譽，所有用來替代真實判斷的代理身分，都可能被重新定價。

## 三、代理身分的毛病：太粗了

代理身分能流行幾千年，是因為它便宜、好用。但它的毛病也一直都在。

它容易造假。租來的豪車，分期買的錶，包裝過的履歷，大家都見過。

它的資訊量很低。停車場裡兩台一樣的車，一個車主是白手起家的創業者，一個剛拿到家裡給的錢，從外面看沒有任何區別。

它還嚴重落後。用一個人二十歲考上的大學，去判斷他四十歲的能力，仔細想想挺荒謬的。

更隱蔽的是它帶來的不公平。很多真正有本事的人，因為身上沒有這些標籤，在第一輪就被篩掉了，連被認真了解的機會都沒有。

過去我們忍著這些問題，是因為沒有更好的辦法。直接了解一個人的成本實在太高。

往大處看，社會和科技的發展，很多時候都在做同一件事：讓整個社會運轉得更有效率。貨幣取代以物易物，電話取代書信，搜尋引擎取代翻黃頁。每一次，舊辦法都沒有錯，只是出現了更快、更準的新辦法。

代理身分在它的時代，也是一種效率工具。可到了今天，它的誤差越來越大，代價也越來越高。它正在變成那個等著被取代的舊辦法。

## 四、讓 Agent 先替你們認識彼此

現在把第一部分的設想放回來。

假設每個人都有一個數位分身，它掌握著你真實的能力、經歷和行為紀錄。你想找一個合夥人，或者別人想評估要不要跟你合作，第一步不用再看你開什麼車。你們的 Agent 可以先聊一輪。

它們交換的是具體得多的東西：你過去三年做過哪些專案，結果怎麼樣；你在某個領域的判斷有多準；跟你合作過的人怎麼評價你；你們的做事方式和價值觀合不合得來。

要讓這件事成立，光有個人 Agent 還不夠。它需要一個關鍵的基礎設施：Agent 社群網路。

今天的社群網路，連結的是人，以及人發出來的內容。未來可能會出現另一張網，連結的是 Agent 和 Agent。它們在背景不停地探索、媒合、溝通。

很多今天要靠飯局、熟人介紹、產業研討會才能完成的「認識一個人」的過程，會在這張網裡提前完成。

聽起來有點像 LinkedIn，但差別很大。

LinkedIn 上的資訊是你自己寫的。頭銜、經歷、技能，全靠本人填，別人隨手點的「認可」也沒多少分量。說到底，它還是一張電子名片，展示的依然是代理身分。

LinkedIn 也得靠人自己去滑、去搜尋、去傳私訊。你能認識誰，取決於你有多少時間，也取決於你願不願意放下面子主動開口。

Agent 社群網路是反過來的。在裡面活動的是一個個數位分身，它們手上拿的是可以驗證的紀錄，不是自我介紹。它們二十四小時在背景工作，能同時和成千上萬個 Agent 交流，把真正合適的人篩出來，再交到你手上。

你可以想像這樣一個場景：你在睡覺，你的 Agent 還在替你社交。它跟幾百個 Agent 聊過，對過彼此的經歷、能力和合作意願，把明顯不合適的都篩掉了。隔天早上醒來，你看到的是一份短名單：哪幾個人符合你的合作條件，為什麼合適，見面可以從哪裡聊起。

LinkedIn 是人找人，靠標籤。Agent 社群網路是 Agent 找 Agent，靠真實紀錄。

從效率的角度看，這是一次躍遷。過去要靠幾個月、幾場飯局、好幾層關係才能完成的媒合，被壓縮成了你睡一覺的時間。

等到兩個人真正見面，彼此已經知道了很多。豪車名錶負責回答的那個問題，「你大概是個什麼樣的人」，在見面之前就已經有了答案。

## 五、區塊鏈：讓 Agent 說的話可信

這裡有個繞不過去的問題：Agent 說的話，憑什麼可信？

我的數位分身說我做成過某個專案，我完全可以讓它往大了說。如果只是 AI 之間互相吹捧，那它不過是一張更花俏的名片。

所以 Agent 社群網路的底層，必須有區塊鏈撐著。

我說的區塊鏈，跟炒幣沒關係，用的是它最樸素的能力：紀錄一旦寫上去就很難竄改，任何第三方都能驗證。這恰好是 Agent 之間建立信任最缺的東西。

比如，你的學歷由學校簽發上鏈；你完成的專案由合作方確認；你的投資紀錄、開源貢獻、交付成果，都留下可以查證的痕跡。Agent 跟別人交流的時候，引用的是這些有人背書的紀錄，而不是你自己說了什麼。

時間久了，每個人身上會長出一張「價值圖譜」（Value Graph）：你做過什麼，跟誰合作過，被誰信任，在哪些領域長期穩定地產出。

這張圖譜是活的，會隨著你的所作所為不斷更新。它比任何一支錶都難偽造，也比任何一個標籤都具體。

把這幾層疊在一起看：數位分身負責代表你，Agent 社群網路負責連結，區塊鏈負責證明，價值圖譜負責呈現。這是我設想中的完整結構。

## 六、哪些會貶值，哪些不會

如果這套推演大致成立，我覺得會出現一次「重新定價」。

最先受影響的，是那些純粹靠訊號功能撐起來的東西。一支錶如果主要價值在於告訴別人「我有錢」，而別人已經能透過更可靠的方式知道你的真實情況，這部分溢價就會慢慢縮水。

名校光環也會變薄。它會回到「一段經歷」的位置，不再是一張終身有效的通行證。

但我不認為豪車名錶會消失。喜歡機械錶的工藝，享受開車的樂趣，單純覺得好看，這些需求是真實的，跟社交沒關係。會消失的，是「買給別人看」的那一部分。

反過來，有些東西會更值錢：長期一致的行為紀錄，可以驗證的成果，真實的口碑。還有那些 AI 很難取代的東西，比如實際見面時的感覺，一起扛過事情的交情，人與人之間的溫度。

Agent 能幫你篩掉不合適的人。但要不要和一個人深交，最後大機率還是得坐下來吃頓飯。

## 最後

回到開頭那個問題：我們靠什麼讓別人知道自己是誰？

過去的答案是一組標籤。開什麼車，戴什麼錶，讀過哪所學校，在哪家公司上班。這些標籤幫我們省了大量時間，也讓很多人被誤讀了一輩子。

以後，答案可能就是你真正做過的那些事。它們被寫在區塊鏈上，經得起驗證，由你的數位分身帶著，替你去和這個世界打招呼。

這背後的邏輯，和貨幣取代以物易物是一樣的：社會總會找到更有效率的方式來運轉，社交也不例外。

到那時候，也許沒有人需要再花幾十萬買一支錶，去證明一件本來可以直接證明的事。

你覺得呢？
