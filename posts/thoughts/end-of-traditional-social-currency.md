从 Muse 爆火出发，聊聊 AI Agent 时代的身份、信誉与社交网络。

最近 Muse 火了。身边不少人开始认真用它，跟它聊天，让它记住自己的事，遇到选择的时候先问问它。

看着这股热度，我脑子里一直绕着一个问题：人为什么这么想要一个“懂自己”的 AI？

顺着这个问题往下想，我碰到了另一个更老的问题。我们到底靠什么，让别人知道自己是谁？

## 一、Personal Agent 最后会长成什么样

今天大家说的 AI 助手，多数还停留在“帮你做事”：订餐、回邮件、排日程。我觉得这只是起点。

一个 AI 如果陪你足够久，它知道的会远远超过你的待办清单。你读过什么书，做过哪些项目，在什么事情上反复纠结，哪些判断后来被证明是对的，你信任谁，谁又信任你。

这些东西攒上几年，它对你的了解，可能比大多数朋友都深。

到那一步，它就不太像一个工具了。它更像你在数字世界里的分身，带着你的经验、偏好和判断方式。你不在场的时候，它可以替你回答问题，替你跟别人的 Agent 谈合作、交换信息、做第一轮筛选。

所以我的判断是：Personal Agent 的终极形态，是数字分身。

后面所有的推演，都站在这个前提上。

## 二、豪车、名表、名校，其实是同一种东西

先回到社交本身。

两个陌生人第一次见面，信息是严重不对称的。我不知道你靠不靠谱，有多少本事，做成过什么事。想弄清楚这些，得花很长时间相处、合作，有时候还得踩个坑。

于是人类发明了很多“快捷方式”。

手腕上一块百达翡丽，暗示你有钱。开一辆保时捷，暗示你混得不错。名片上印着某大厂总监，暗示你有能力。简历上写着 MIT、斯坦福，暗示你聪明又努力。

这些东西干的是同一件事：在对方没时间了解你的时候，先给出一个大概的答案。我把它们叫做“代理身份”（Proxy Identity）。它们代表你，但它们不是你。

它们为什么能起作用？我觉得可以从“货币”这个词去理解。

一张纸币本身不值什么钱。它能换来东西，是因为所有人都相信它能换来东西。货币的价值，来自共识。

货币被发明出来，本来就是为了效率。没有货币的年代，人们只能以物易物，要找到一个刚好需要你的东西、手里又刚好有你想要的东西的人，难得要命。社交货币解决的也是效率问题：真正了解一个人太慢了，那就先用一个标签顶上。

社交货币也是这个道理。一块表能代表“成功”，靠的不是它走得比手机准，是大家默认戴得起它的人大概率有实力。一所学校能代表“优秀”，是因为社会普遍认可它的录取门槛和培养质量。

有了共识，这些东西就能在陌生人之间“流通”。你不用解释自己，对方看一眼就懂，就像付钱的时候不用证明钞票是真的。

不过，光有共识还不够。为什么偏偏是名表、豪车、名校，而不是别的东西？

经济学里有个理论叫“信号理论”。经济学家迈克尔·斯宾塞用它解释过一个问题：雇主看不出求职者的真实能力，为什么会看重学历？他的答案是，学历不一定直接证明你会干活，但拿下一个好学历很难，能力差的人很难拿到。正因为获得它的成本高，它才成了可信的信号。斯宾塞后来凭这项研究拿了诺贝尔经济学奖。

名表和豪车也是同一个逻辑。一百多年前，凡勃伦就写过“炫耀性消费”：有钱人买昂贵的东西，很多时候不是因为好用，而是因为别人买不起。贵，本身就是它的功能。

所以一个信号能不能被相信，关键在于造假的代价够不够高。谁都能轻易拿到的东西，证明不了什么。

这也意味着，社交货币和真正的货币一样，会贬值。一旦出现一种更难伪造、获取成本却低得多的信号，大家就不必再靠一块表来证明自己，旧信号背后的共识也会慢慢松动。

豪车名表还有一个特点：大多是消费型负债。买下那天就开始贬值，保养还得持续花钱。很多人明知道不划算还是要买，因为在社交场合它确实“有用”，能换来别人对你的第一印象。

名校稍微不一样，它背后有真实的筛选和训练。可它在社交里被使用的方式，跟名表很像。别人看到的是一个标签，看不到你在那四年里到底学到了什么，更看不到你之后十年做成了什么。

Muse 背后的负责人、Meta 首席 AI 官 Alexandr Wang，当年在 MIT 只读了一年就退学了。今天几乎没人会因为他没拿到学位而怀疑他的能力，大家看的是他做成了什么。这个例子在提醒我们：学历标签和一个人的真实能力之间，本来就隔着一层。

所以这篇文章想讨论的，其实不只是奢侈品。我真正想说的是：

当 AI 能更直接地读懂一个人的能力、经历和信誉，所有用来替代真实判断的代理身份，都可能被重新定价。

## 三、代理身份的毛病：太粗了

代理身份能流行几千年，是因为它便宜、好用。但它的毛病也一直都在。

它容易造假。租来的豪车，分期买的表，包装过的履历，大家都见过。

它的信息量很低。停车场里两辆一样的车，一个车主是白手起家的创业者，一个刚拿到家里给的钱，从外面看没有任何区别。

它还严重滞后。用一个人二十岁考上的大学，去判断他四十岁的能力，仔细想想挺荒唐的。

更隐蔽的是它带来的不公平。很多真正有本事的人，因为身上没有这些标签，在第一轮就被筛掉了，连被认真了解的机会都没有。

过去我们忍着这些问题，是因为没有更好的办法。直接了解一个人的成本实在太高。

往大了看，社会和科技的发展，很多时候都在做同一件事：让整个社会运转得更有效率。货币取代以物易物，电话取代书信，搜索引擎取代翻黄页。每一次，旧办法都没有错，只是出现了更快、更准的新办法。

代理身份在它的时代，也是一种效率工具。可到了今天，它的误差越来越大，代价也越来越高。它正在变成那个等着被替代的旧办法。

## 四、让 Agent 先替你们认识彼此

现在把第一部分的设想放回来。

假设每个人都有一个数字分身，它掌握着你真实的能力、经历和行为记录。你想找一个合伙人，或者别人想评估要不要跟你合作，第一步不用再看你开什么车。你们的 Agent 可以先聊一轮。

它们交换的是具体得多的东西：你过去三年做过哪些项目，结果怎么样；你在某个领域的判断有多准；跟你合作过的人怎么评价你；你们的做事方式和价值观合不合得来。

要让这件事成立，光有个人 Agent 还不够。它需要一个关键的基础设施：Agent 社交网络。

今天的社交网络，连接的是人，以及人发出来的内容。未来可能会出现另一张网，连接的是 Agent 和 Agent。它们在后台不停地发现、匹配、沟通。

很多今天要靠饭局、熟人介绍、行业会议才能完成的“认识一个人”的过程，会在这张网里提前完成。

听起来有点像 LinkedIn，但差别很大。

LinkedIn 上的信息是你自己写的。头衔、经历、技能，全靠本人填，别人随手点的“认可”也没多少分量。说到底，它还是一张电子名片，展示的依然是代理身份。

LinkedIn 也得靠人自己去刷、去搜、去发私信。你能认识谁，取决于你有多少时间，也取决于你愿不愿意放下面子主动开口。

Agent 社交网络是反过来的。在里面活动的是一个个数字分身，它们手里拿的是可以验证的记录，不是自我介绍。它们二十四小时在后台工作，能同时和成千上万个 Agent 交流，把真正合适的人筛出来，再交到你手上。

你可以想象这样一个场景：你在睡觉，你的 Agent 还在替你社交。它跟几百个 Agent 聊过，对过彼此的经历、能力和合作意向，把明显不合适的都筛掉了。第二天早上醒来，你看到的是一份短名单：哪几个人符合你的合作条件，为什么合适，见面可以从哪里聊起。

LinkedIn 是人找人，靠标签。Agent 社交网络是 Agent 找 Agent，靠真实记录。

从效率的角度看，这是一次跃迁。过去要靠几个月、几场饭局、好几层关系才能完成的匹配，被压缩成了你睡一觉的时间。

等到两个人真正见面，彼此已经知道了很多。豪车名表负责回答的那个问题，“你大概是个什么样的人”，在见面之前就已经有了答案。

## 五、区块链：让 Agent 说的话可信

这里有个绕不过去的问题：Agent 说的话，凭什么可信？

我的数字分身说我做成过某个项目，我完全可以让它往大了说。如果只是 AI 之间互相吹捧，那它不过是一张更花哨的名片。

所以 Agent 社交网络的底下，必须有区块链托底。

我说的区块链，跟炒币没关系，用的是它最朴素的能力：记录一旦写上去就很难篡改，任何第三方都能验证。这恰好是 Agent 之间建立信任最缺的东西。

比如，你的学历由学校签发上链；你完成的项目由合作方确认；你的投资记录、开源贡献、交付结果，都留下可以查证的痕迹。Agent 跟别人交流的时候，引用的是这些有人背书的记录，而不是你自己说了什么。

时间长了，每个人身上会长出一张“价值图谱”（Value Graph）：你做过什么，跟谁合作过，被谁信任，在哪些领域长期稳定地输出。

这张图谱是活的，会随着你的所作所为不断更新。它比任何一块表都难伪造，也比任何一个标签都具体。

把这几层叠在一起看：数字分身负责代表你，Agent 社交网络负责连接，区块链负责证明，价值图谱负责呈现。这是我设想中的完整结构。

## 六、哪些会贬值，哪些不会

如果这套推演大致成立，我觉得会出现一次“重新定价”。

最先受影响的，是那些纯粹靠信号功能撑起来的东西。一块表如果主要价值在于告诉别人“我有钱”，而别人已经能通过更靠谱的方式知道你的真实情况，这部分溢价就会慢慢缩水。

名校光环也会变薄。它会回到“一段经历”的位置，不再是一张终身有效的通行证。

但我不认为豪车名表会消失。喜欢机械表的工艺，享受开车的乐趣，单纯觉得好看，这些需求是真实的，跟社交没关系。会消失的，是“买给别人看”的那一部分。

反过来，有些东西会更值钱：长期一致的行为记录，可以验证的成果，真实的口碑。还有那些 AI 很难替代的东西，比如线下见面时的感觉，一起扛过事情的交情，人和人之间的温度。

Agent 能帮你筛掉不合适的人。但要不要和一个人深交，最后大概率还是得坐下来吃顿饭。

## 最后

回到开头那个问题：我们靠什么让别人知道自己是谁？

过去的答案是一组标签。开什么车，戴什么表，读过哪所学校，在哪家公司上班。这些标签帮我们省了大量时间，也让很多人被误读了一辈子。

以后，答案可能就是你真正做过的那些事。它们被写在区块链上，经得起验证，由你的数字分身带着，替你去和这个世界打招呼。

这背后的逻辑，和货币取代以物易物是一样的：社会总会找到更有效率的方式来运转，社交也不例外。

到那时候，也许没人需要再花几十万买一块表，去证明一件本来可以直接证明的事。

你觉得呢？
